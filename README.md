# PDF Tools

PDF Tools 是一个基于浏览器的 PDF 工具应用。文件处理在浏览器本地完成，不需要服务端参与 PDF 处理。

## 功能

- 拆分 PDF：选择指定页面并导出
- 合并 PDF：上传多个 PDF，支持排序后合并
- 图片转 PDF：将多张图片转换为一个 PDF
- 兼容模式：用于处理部分异常或容易出现空白页的 PDF
- 页面尺寸规范化：支持合并 PDF 和图片转 PDF 时统一页面尺寸
- 明暗主题切换
- 简体中文和英文界面

## 隐私说明

PDF 和图片文件会在浏览器中处理。项目设计目标是让 PDF 操作尽量在本地完成，并将较重的计算任务放到 Web Worker 中执行，减少对界面响应的影响。
